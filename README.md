One sentence explaining the modern internet to a traveler who has just
stepped out of the year 1800, using only words they would already know.
The internet is pictured as a single great library holding the books of
every land, its doors open to every cottage: you ask a question at your
own hearth, and before the candle gutters a stranger across the sea
answers it. The library says what the internet is — a shared store of
all writing — and the stranger's answer says what it does — it carries
words between strangers at once. No word in it was coined after 1800.

## Run

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt` (one sentence, 186 characters).
Deterministic: every run writes byte-identical output. Node 22+,
standard library only, no network.
